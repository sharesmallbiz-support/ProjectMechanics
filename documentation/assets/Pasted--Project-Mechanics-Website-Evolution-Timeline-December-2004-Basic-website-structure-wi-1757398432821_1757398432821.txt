## Key Evolution Themes:

### Business Focus Shifts
1. **2004-2005**: PM Portal vision - integrated project management tool
2. **2006**: Partnership/hosting arrangement with DeNovaCo, lifestyle expansion
3. **2006-2008**: Return to independent operations, theory-based consulting
4. **2008-2011**: Web services integration with project management expertise
5. **2011-2017**: Integrated web publishing and SharePoint specialization
6. **2017-2019**: API development and technical services until site closure

### Technical Evolution
- **Early years**: Static HTML pages
- **2010-2013**: Dynamic social media integration, real-time feeds
- **2013-2017**: Responsive design, enhanced navigation
- **2017+**: Modern web technologies, API focus

### Content Strategy
- **Consistent**: Project management fundamentals and PMP certification
- **Evolving**: From basic consulting to integrated web publishing to technical services
- **Community**: Increasing emphasis on social media and community building

### Branding
- **2002-2006**: Project Mechanics with various partnerships
- **2006**: DeNovaCo partnership period
- **2008+**: Independent Project Mechanics LLC with Mark Hazleton as founder
- **Tagline consistency**: "Discover the mechanics of getting IT done" (with variations)
